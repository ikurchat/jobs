# Чеклист перед публикацией на VC.ru

## Заголовок и мета
- [ ] Заголовок содержит год (2025/2026)
- [ ] Заголовок содержит «для россиян» / «из России» или аналог
- [ ] Заголовок до 80 символов
- [ ] Нет эмодзи в заголовке
- [ ] Мета-описание до 160 символов
- [ ] Мета-описание содержит основной ключевик
- [ ] 3 варианта заголовка подготовлено

## Структура
- [ ] Лид: боль + решение + экспертность (2-3 предложения)
- [ ] Оглавление с якорями (для статей 2000+ слов)
- [ ] Все H2/H3 содержат ключевые фразы естественно
- [ ] FAQ секция с 3-5 вопросами (long-tail SEO)
- [ ] Заключение с резюме

## Длина и формат
- [ ] Длина 2 000-4 000 слов
- [ ] Нет стен текста — абзацы по 3-5 предложений
- [ ] Списки и таблицы для структурирования данных
- [ ] Цитаты/врезки для ключевых инсайтов

## Изображения
- [ ] Обложка запланирована (1280x720)
- [ ] Минимум 5 изображений/скриншотов рекомендовано
- [ ] Описание каждого изображения в рекомендациях
- [ ] Нет стоковых фото — только скриншоты и инфографика

## CTA
- [ ] CTA после первого ценного раздела (~500 слов) — мягкий
- [ ] CTA после ключевого раздела / таблицы — средний
- [ ] CTA в заключении — прямой
- [ ] Всего 3-5 CTA в статье
- [ ] Формулировки из безопасного списка (editorial-guidelines.md)

## Безопасность (модерация)
- [ ] Нет прямого упоминания бренда «HEY, STORE!» в тексте
- [ ] Нет слов «лучший», «единственный», «гарантированно»
- [ ] Нет прямой рекламы — только экспертный контент с мягкими CTA
- [ ] Нет упоминания VPN-сервиса
- [ ] Нет ссылок на казино/букмекеров
- [ ] Нет прямых цен на услуги
- [ ] Статья не дублирует контент с других площадок
- [ ] Нет keyword spam (ключевик не более 5 раз)
- [ ] Нет агрессивного тона или clickbait

## Данные и факты
- [ ] Все цифры (комиссии, лимиты, курсы) актуальны
- [ ] Указаны источники данных (где применимо)
- [ ] Минусы продуктов упомянуты честно
- [ ] Нет финансовых/инвестиционных советов

## SEO
- [ ] Основной ключевик в H1, первом абзаце, мета-описании
- [ ] Вторичные ключевики в H2/H3
- [ ] Long-tail запросы в FAQ
- [ ] Подсайт выбран корректно
- [ ] Теги выбраны (3-5 релевантных)
- [ ] Нет переоптимизации

## Репурпозинг
- [ ] Бриф для Telegram (content-arnold) подготовлен
- [ ] 3-5 ключевых тейков выделены
- [ ] Рекомендуемый формат TG-поста указан
- [ ] Черновик TG-поста готов
