# Контент-стратегия VC.ru

## Brand Voice

### Тон
Экспертный, но человечный. Не корпоративный. Как если бы опытный друг-финтехник объяснял за кофе. Допустим лёгкий сарказм (аудитория VC это ценит), но не панибратство.

### Позиционирование
Независимый эксперт, который тестирует финтех-инструменты на себе. НЕ бренд. CTA мягкий: «Подробнее в моём Telegram-канале» → ведёт на @hey_store_official.

### Ключевые принципы
1. Всегда давать реальную пользу ДО любого CTA
2. Показывать скриншоты и конкретные цифры
3. Честно говорить о минусах (строит доверие)
4. Не бояться контрарных мнений (буст через дискуссию)
5. Отвечать на КАЖДЫЙ комментарий под статьёй

### Обращение
- На «вы» (без исключений)
- Без канцелярита
- Без фамильярности

### Эталонные фразы
- «Я протестировал на себе — рассказываю как есть»
- «Вот конкретные цифры, без маркетинговой воды»
- «Минусы тоже есть — было бы нечестно их скрывать»
- «Спойлер: не всё так радужно, как пишут»
- «Давайте разберёмся без эмоций, на цифрах»

### Запрещённые фразы
- «Уникальное предложение»
- «Лучший на рынке»
- «Единственный способ»
- «Гарантированно»
- «Только сегодня»
- «Друзья» (в обращении)
- «Не является финансовой рекомендацией» (штамп — лучше перефразировать)

## Целевая аудитория (персоны)

### 1. Криптотрейдер / P2P-арбитражник (30-40%)
- **Боль:** нет нормальной карты для вывода крипты, банки блокируют
- **Триггеры:** комиссии, лимиты, скорость вывода, Apple Pay
- **Продукты:** RedotPay, Bybit, Ether.fi
- **Контент:** сравнения карт, гайды по выводу, комиссии в цифрах

### 2. Экспат / работающий с ЕС/США (20-30%)
- **Боль:** нет IBAN, не могут платить за жильё/подписки
- **Триггеры:** SWIFT/SEPA, стабильность, легальность
- **Продукты:** Grey, Revolut, Payoneer
- **Контент:** гайды по переводам, сравнения банков, кейсы релокантов

### 3. Фрилансер с зарубежными заказчиками (15-20%)
- **Боль:** как получить оплату от Upwork/Fiverr/прямых клиентов
- **Триггеры:** комиссия за получение, конвертация, скорость
- **Продукты:** Payoneer, Grey, Wise (через 3rd party)
- **Контент:** гайды по получению оплаты, сравнения платформ

### 4. Оптовый покупатель (10-15%)
- **Боль:** нужны аккаунты для бизнеса, партнёров, клиентов
- **Триггеры:** объём, скидки, надёжность, скорость
- **Контент:** НЕ создаём контент для этого сегмента на VC.ru

### 5. Гемблер (5-10%)
- **Боль:** карты для букмекеров и казино заблокированы
- **Триггеры:** анонимность, скорость, поддержка
- **Контент:** НЕ создаём контент для этого сегмента на VC.ru (нарушает правила)

## Контентные пробелы (незанятые территории)

Конкуренты НЕ покрывают:

1. **Реальные тесты со скриншотами** — никто не показывает фактические транзакции, процент успеха, реальные комиссии с конвертацией
2. **Налоговые последствия** — уведомление ФНС, НДФЛ с крипты, КИК при использовании зарубежных счетов
3. **Долгосрочный опыт** — что через 6-12 месяцев: блокировки, compliance-запросы, изменения условий
4. **Глубокие обзоры крипто-карт** — RedotPay, Bybit Card, Ether.fi для России с реальными цифрами
5. **Таблицы с реальными цифрами** — точные комиссии, курсы, полная стоимость владения (TCO)
6. **Скам-экспозе** — честные разборы сомнительных сервисов
7. **Финансовый toolkit цифрового кочевника** — комплексные решения, а не отдельные продукты

## Формулы заголовков

### Работающие формулы
- «Как [действие] из России в [год]»
- «[Продукт] для россиян: [ценность] [год]»
- «[Число] способов [задача] в [год]»
- «Я протестировал [X] — вот результаты [год]»
- «Почему [тезис] (и что с этим делать)»
- «[Продукт A] vs [Продукт B]: что выбрать в [год]»
- «Полный гайд: [задача] для россиян [год]»

### Обязательные элементы
- Год (2025/2026) — для SEO и актуальности
- «для россиян» / «из России» — таргетинг аудитории
- Конкретный глагол — «оплатить», «перевести», «открыть», «получить»

### Запрещено в заголовках
- Эмодзи
- Капслок
- «Лучший» / «Топ» без обоснования
- Вопросительные заголовки без ответа в лиде
- Clickbait без покрытия в тексте

## Параметры статьи

### Структура (обязательная)
1. Обложка (1280x720, рекомендация по содержанию)
2. Лид (2-3 предложения: боль + обещание решения + сигнал экспертности)
3. Оглавление (якоря для статей 2000+ слов)
4. Контекст / почему это важно сейчас (2-3 абзаца, цифры)
5. Основная часть (по типу: шаги / сравнение / история)
6. FAQ (3-5 вопросов для long-tail SEO)
7. Заключение с CTA

### CTA — точки размещения
1. После первого ценного раздела (~500 слов) — мягкий
2. После сравнительной таблицы / ключевого раздела — средний
3. В заключении — прямой
4. (Опционально) в середине длинной статьи — мягкий
5. (Опционально) после FAQ — средний

### Изображения
- 5-7 на статью минимум
- Обложка: 1280x720
- Скриншоты: реальные интерфейсы сервисов
- Таблицы: если сложная — как изображение
- Пошаговые скрины: каждый шаг гайда

## Контент-план (первый месяц)

### Неделя 1
**«Я протестировал 5 виртуальных карт для оплаты подписок из России — вот что вышло [2026]»**
- Тип: личный кейс
- Подсайт: money
- SEO: зарубежная карта для россиян, виртуальная карта для оплаты
- CTA: мягкий

### Неделя 2
**«Как оплачивать зарубежные сервисы из России в 2026: все рабочие способы»**
- Тип: FAQ/гайд (15-20 вопросов)
- Подсайт: services
- SEO: оплатить подписку из России, оплатить Netflix/Spotify/ChatGPT
- CTA: средний

### Неделя 3
**«Почему крипто-карты НЕ заменят зарубежные банковские карты (и наоборот)»**
- Тип: мнение/аналитика
- Подсайт: crypto
- SEO: крипто карта для россиян
- CTA: мягкий
- Цель: провокация дискуссии → буст через комментарии

### Неделя 4
**«Пошаговая инструкция: как перевести деньги за рубеж в 2026»**
- Тип: гайд-инструкция
- Подсайт: money
- SEO: международные переводы, перевод денег за рубеж
- CTA: прямой
