## Маппинг: запрос → тип статьи

| Паттерн запроса | Тип статьи |
|----------------|-----------|
| «как [действие]» | guide |
| «[продукт] обзор» | case_study |
| «[A] vs [B]» / «что выбрать» | comparison |
| «[продукт] для россиян» | guide / case_study |
| «[событие] что делать» | news_analysis |
| «[число] способов» | guide / comparison |
| «можно ли [действие]» | FAQ (в составе guide) |

## Правила использования ключевиков

1. **Основной ключевик** — в заголовке H1, в первом абзаце, в мета-описании
2. **Вторичные** — в H2/H3 заголовках естественно
3. **Long-tail** — в FAQ-секции (каждый вопрос = long-tail запрос)
4. **НЕ повторять** один и тот же ключевик более 5 раз на статью
5. **НЕ вставлять** ключевики неестественно — это раздражает и аудиторию, и модерацию
